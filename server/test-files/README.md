# Fichiers de Test - Invoke Server

Ce dossier contient tous les fichiers de test créés pendant le développement de l'application Invoke.

## Fichiers inclus :

### `test-final-upload.js`
- Test final de l'upload d'images avec Cloudinary
- Vérifie l'upload de multiples types d'images (logo, portrait, banner)
- Teste la suppression et le remplacement d'images

### `test-frontend-connection.js`
- Test de connexion entre le frontend et le backend
- Vérifie les endpoints d'API
- Teste l'authentification

### `test-frontend-integration.js`
- Test d'intégration frontend/backend complet
- Simule les interactions utilisateur
- Vérifie le flux de données end-to-end

### `test-new-approach.js`
- Test de la nouvelle approche d'upload immédiat
- Vérifie l'upload direct vers Cloudinary
- Teste la mise à jour de la base de données

### `test-session-image.js`
- Test spécifique pour l'upload d'images de session
- Vérifie l'upload de bannières de session
- Teste l'intégration avec le modèle Session

## Note :
Ces fichiers sont conservés à des fins de documentation et de référence, mais ne sont plus utilisés dans le code de production.
