# 🎮 Invoke - Présentation

Présentation de l'application **Invoke**, une plateforme moderne dédiée aux passionnés de jeux de rôle (JDR).

## 🚀 Démarrage rapide

### Installation des dépendances
```bash
npm install
```

### Lancement en mode développement
```bash
npm run dev
```

### Construction pour la production
```bash
npm run build
```

### Export en PDF
```bash
npm run export
```

## 📋 Contenu de la présentation

La présentation couvre les aspects suivants d'Invoke :

1. **Vue d'ensemble** - Concept et architecture
2. **Système d'utilisateurs** - Rôles et permissions
3. **Gestion des jeux** - Catalogue et fonctionnalités
4. **Système de sessions** - Types et gestion
5. **Système de campagnes** - Aventures long terme
6. **Communication** - Chat et support
7. **Panel d'administration** - Gestion complète
8. **Interface utilisateur** - Design et composants
9. **Fonctionnalités techniques** - Upload, auth, API
10. **Déploiement** - Production et monitoring
11. **Points forts** - Qualités de l'application
12. **Métriques** - Statistiques et suivi
13. **Sécurité** - Protection et conformité
