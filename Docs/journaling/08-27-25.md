# Journal - 27 Août 2025

## Problème 3 identifié et résolu : Authentification et User ID manquant

**Problème** : Après connexion, l'utilisateur était connecté mais son ID était `undefined`, causant des erreurs 401 sur les routes protégées comme `/users/undefined/favorites`.

**Cause** : Dans `AuthContext.tsx`, la fonction `login` faisait `setUser(userData)` au lieu de `setUser(userData.user)`. Le serveur retourne `{ data: { user: userObject } }` mais le client extrayait directement `data`.

**Solution appliquée** :
- Correction dans `client/src/contexts/AuthContext.tsx` : `setUser(userData.user)`
- Ajout de validation : `if (!userData || !userData.user)`
- Correction cohérente dans `signup` également

**Résultat attendu** : L'utilisateur aura maintenant un ID valide et pourra accéder à ses favoris et autres routes protégées.
