# Journal - 18 Septembre 2025

## Problèmes rencontrés

### Erreurs de build TypeScript
Suite au build, plusieurs erreurs TypeScript ont été identifiées :

1. **Problèmes avec useNotifications hook** :
   - `removeNotification` n'existe pas dans le hook
   - `addNotification`, `addSuccess`, `addError` n'existent pas dans le hook
   - Type mismatch entre `Notification[]` et `NotificationItem[]`

2. **Problèmes de typage dans les pages de tables** :
   - `memberUser` peut être de type `string | User` mais le code accède aux propriétés comme si c'était toujours un `User`
   - Problèmes avec `_id`, `avatar`, `firstName`, `lastName`

3. **Variable non utilisée** :
   - `filter` dans `TablesPage.tsx` est déclaré mais jamais utilisé

## Solutions appliquées

### 1. Problème des hooks de notifications
- **Problème** : Confusion entre `useNotifications` (notifications de base de données) et `useSimpleNotifications` (notifications UI)
- **Solution** : Remplacé tous les imports `useNotifications` par `useSimpleNotifications` dans les fichiers qui utilisent des notifications UI
- **Fichiers corrigés** : ContactPage, ConversationPage, CampaignDetailPage, GameDetailPage, SessionDetailPage, UserDetailPage, AdminPage

### 2. Problème de typage dans les pages de tables
- **Problème** : `TableMember.user` peut être `string | User` mais le code accédait aux propriétés comme si c'était toujours un `User`
- **Solution** : Ajouté des vérifications de type avec `typeof memberUser === 'object'` avant d'accéder aux propriétés
- **Fichiers corrigés** : EditTablePage.tsx, TableDetailPage.tsx

### 3. Problème des interfaces NotificationItem
- **Problème** : Deux interfaces `NotificationItem` différentes dans `useSimpleNotifications` et `NotificationContainer`
- **Solution** : Harmonisé les interfaces en ajoutant `'warning'` et `title` à `NotificationContainer`

### 4. Problème des paramètres des méthodes de notification
- **Problème** : `addSuccess`/`addError` attendaient 2 arguments (title, message) mais n'en recevaient qu'1
- **Solution** : Corrigé tous les appels pour inclure le titre et le message
- **Problème** : `addNotification` attendait un objet mais recevait des paramètres séparés
- **Solution** : Corrigé tous les appels pour passer un objet avec `{ type, title, message }`

### 5. Variable non utilisée
- **Problème** : Paramètre `filter` dans `TableCard` n'était pas utilisé
- **Solution** : Supprimé le paramètre de l'interface et de l'appel du composant

## Résultat
✅ Build réussi sans erreurs TypeScript
✅ Toutes les erreurs de compilation corrigées
✅ Code plus robuste avec des vérifications de type appropriées
