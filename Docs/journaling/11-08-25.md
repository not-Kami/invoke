1. **Restriction des permissions** : Seuls les admins et MJ peuvent voir les boutons de création
2. **CreateSessionPage** : Formulaire complet de création de sessions avec validation
3. **CreateCampaignPage** : Formulaire complet de création de campagnes avec gestion des joueurs
4. **Routes protégées** : Les pages de création sont protégées par ProtectedRoute
5. **Validation des permissions** : Vérification côté client et redirection si non autorisé
6. **Dashboard dynamique** : Affichage des vraies sessions et campagnes selon les permissions
7. **Hook personnalisé** : useDashboardData pour gérer les données du dashboard
8. **Barre de recherche** : Ajoutée dans la navbar (desktop et mobile) - non fonctionnelle pour le moment
9. **Mode DM conditionnel** : L'onglet DM est toujours visible mais affiche un message informatif pour les utilisateurs non-MJ
10. **Navbar restructurée** : Logo fixé à gauche, navigation centrée, actions à droite

## Logique des permissions
- `user.role === 'admin'` : Accès complet
- `user.isDM === true` : Accès aux fonctionnalités de création
- `user.role === 'user' && user.isDM === false` : Accès en lecture seule
