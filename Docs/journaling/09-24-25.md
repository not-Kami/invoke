# Journal - 09-24-25

## Problèmes identifiés et solutions

### Problème d'espacement entre les cartes de jeu sur la landing page (branche production)
- **Date**: 09-24-25
- **Description**: Les cartes de jeu étaient collées ensemble après modifications sur la branche production
- **Status**: ✅ Résolu
- **Problème identifié**: 
  - Le `gap-6` avait été supprimé du conteneur flex
  - Les cartes utilisaient `w-1/4` sans tenir compte de l'espacement
- **Solution appliquée**:
  - Restauré `gap-6` sur le conteneur flex
  - Utilisé `w-[calc(25%-1.5rem)]` pour les cartes desktop pour tenir compte du gap
  - Conservé la logique mobile avec `w-full` et `px-4`
