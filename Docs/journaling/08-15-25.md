## Correction du problème d'affichage desktop

- **Problème identifié** : Classe CSS `w-74` inexistante dans Tailwind, causant la compression des cartes sur desktop
- **Solution appliquée** : Remplacement par `w-80` (320px) pour desktop et `w-60` (240px) pour mobile
- **Cohérence restaurée** : Mise à jour de toutes les fonctions JavaScript pour utiliser les bonnes largeurs (240px mobile, 320px desktop)
- **Fonctions corrigées** : `getSliderTransform`, `handleMouseDown`, `handleMouseMove`, `handleTouchStart`, `handleTouchMove`
